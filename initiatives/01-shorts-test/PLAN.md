# PLAN — 30-day Shorts test (2 channels)

**Goal:** find which channel earns views and retention fast enough to reach YouTube Partner Program, using ≤ $200/mo.

## Channels
| | A: Scary + AI stories | B: True crime |
|---|---|---|
| Why | High stable demand + fastest-rising term (see niche-research.md) | Highest demand, higher RPM (ESTIMATE) |
| Format | 45–75s original story, cliffhanger hook, AI voice, AI/stock visuals, burned-in captions | 45–75s case summary with 1 twist fact, sources in description |
| TikTok | Same video, ≥61s cut (Creator Rewards needs >1 min) | Same |
| Uploads | 1/day | 1/day |
| Risk | Template sameness → vary story structure, settings, narrators | Sensitive-content ad limits; must source every fact |

## Pipeline (steps)
1. Idea bank from Trends + rising queries (Claude, Green)
2. Script (Claude drafts, you approve) — Green / your review
3. Voice: AI TTS (Yellow: tool subscription)
4. Visuals: stock + AI images (Yellow if paid credits)
5. Render: local Python + ffmpeg script → 9:16, captions, music (Claude builds, Green)
6. Upload (🔴 you, or with your yes each batch)
Automate a step only after it has worked by hand twice.

## Budget — ESTIMATE, prices to verify before buying
| Item | ~$/mo |
|---|---|
| AI voice (e.g. ElevenLabs starter–creator tier) | 5–22 |
| AI images/video credits (Higgsfield currently 0 credits, free plan) | 30–60 |
| Stock footage/music (free libraries first) | 0–20 |
| Buffer | rest of $200 |
Nothing bought without a 🔴 yes.

## Done-when
30 days, ≥40 uploads per channel, numbers logged weekly in METRICS.md, decision rules applied.

## Outcomes (honest)
- Best: one channel breaks out (a few videos at 100k+), YPP eligibility within ~3 months.
- Likely: slow growth; meaningful payouts take 3–6+ months. ESTIMATE (general creator experience, not measured).
- Worst: both stall below 500 median views → change format/niche; ~$100–200 spent.
